## 강직

자신의 턴이 아닐 때 받은 누적 공격 피해가 최대 HP의 10% 초과 시, 다음 턴에 최대 HP 3%만큼의 HP를 회복하고, 받는 피해의 [10-20]%을(를) 자신에게 가장 많은 피해를 준 대상에게 추가 고정 피해로 반사한다.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(칼&방패)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(칼&방패)의 공격력 +2 | 3 |
| 병사(칼&방패)의 HP +20 | 3 |
| 병사(칼&방패)의 공격력 +5% | 3 |
| 병사(칼&방패)의 HP+5% | 3 |
| 병사(칼&방패)이(가) 주는 피해 +5% | 3 |
| 병사(칼&방패)이(가) 받는 피해 -5% | 3 |
| 병사(칼&방패)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(칼&방패)의 흡혈률 +8% | 2 |
| 병사(칼&방패)의 회피률 +8% | 2 |
| 병사(칼&방패)이(가) 회피률을 +8% 무시한다 | 2 |
| 방패병의 최대 분노치 -1 | 1 |
| 방패병이 디버프 효과를 받을 시 10% 확률로 해당 효과에 면역한다 | 1 |
| 방패병이 받는 HP 회복 효과 +15% | 2 |
| 방패병이 받는 피해 -3 | 2 |

### 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |
| 병사(칼&방패)이(가) 공격 시 30% 확률로 [30%\*공격력]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 전체 아군의 보호막 효과 +30% | 1 |

| 방패병이 공격 받을 때 20% 확률로 최대 HP 1%의 추가 고정 피해를 공격자에게 반사한다 | 1 |
