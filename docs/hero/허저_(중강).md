## 호치

충돌 후 공격력이 [100-200]% 상승하고, 매턴 20%씩 떨어진다. 자신의 HP가 처음으로 50% 미만으로 떨어질 시, 자신이 주는 피해 +30%(전투가 종료될 때까지 지속)

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 기병(중기병)의 스킬 시전 후 분노치 1 보류 | 1 |
| 기병(중기병)의 공격력 +2 | 3 |
| 기병(중기병)의 HP +20 | 3 |
| 기병(중기병)의 공격력 +5% | 3 |
| 기병(중기병)의 HP+5% | 3 |
| 기병(중기병)이(가) 주는 피해 +5% | 3 |
| 기병(중기병)이(가) 받는 피해 -5% | 3 |
| 기병(중기병)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 기병(중기병)의 흡혈률 +8% | 2 |
| 기병(중기병)의 회피률 +8% | 2 |
| 기병(중기병)이(가) 회피율을 8% 무시한다 | 2 |
| 기병의 최대 분노치 -1 | 1 |
| 기병이 대상을 처치할 시 공격력 +1 | 1 |
| 기병의 HP가 처음 30% 미만으로 떨어질 경우, [최대 HP\*15%]에 해당하는 HP를 회복한다 | 2 |
| 기병이 받는 HP 회복 효과 +15% | 2 |

### 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |
| 기병(중기병)이(가) 공격 시 30% 확률로 [30%\*공격력]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 전체 아군이 기절된 대상에게 주는 피해 +20% | 1 |
| 기병(중기병)이 충돌로 부여하는 기절 효과 지속 시간 +1턴 | 1 |
| 기병이 공격 시 분노치가 1 추가 증가한다 | 1 |
| 기병이 공격할 시, 대상에게 현재 HP의 2%에 해당하는 추가 피해를 입힌다 | 2 |
| 기병이 준 피해의 20%가 고정 피해로 전환된다 | 1 |
| 중기병의 충돌 피해가 30% 증가한다 | 1 |
