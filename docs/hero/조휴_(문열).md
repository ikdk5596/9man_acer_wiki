## 저격

가장 멀리 있는 대상을 우선 공격하며, 대상이 최대 공격 거리에 위치할 경우 해당 대상에게 입히는 피해량이 [10-30]% 증가한다.

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(강화 쇠뇌)의 공격력 +2 | 3 |
| 병사(강화 쇠뇌)의 HP +20 | 3 |
| 병사(강화 쇠뇌)의 공격력 +5% | 3 |
| 병사(강화 쇠뇌)의 HP+5% | 3 |
| 병사(강화 쇠뇌)이(가) 주는 피해 +5% | 3 |
| 병사(강화 쇠뇌)이(가) 받는 피해 -5% | 3 |
| 병사(강화 쇠뇌)이(가) 턴당 HP를 2회복한다 | 3 |

| 재능 | 중첩 가능 횟수 |
|---|---:|
