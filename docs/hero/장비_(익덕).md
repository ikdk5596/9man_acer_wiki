## 포효

돌격 후 포효하여 2칸 내 최대 8명의 적에게 이번 돌격으로 입힌 유효 피해 [40-70]%의 추가 고정 피해를 입히고, 3턴 동안 움직이지 못하도록 두려움을 준다.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(창&방패)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(창&방패)의 공격력 +2 | 3 |
| 병사(창&방패)의 HP +20 | 3 |
| 병사(창&방패)의 공격력 +5% | 3 |
| 병사(창&방패)의 HP+5% | 3 |
| 병사(창&방패)이(가) 주는 피해 +5% | 3 |
| 병사(창&방패)이(가) 받는 피해 -5% | 3 |
| 병사(창&방패)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(창&방패)의 흡혈률 +8% | 2 |
| 병사(창&방패)의 회피률 +8% | 2 |
| 병사(창&방패)이(가) 회피률을 +8% 무시한다 | 2 |
| 방패병의 최대 분노치 -1 | 1 |
| 방패병이 디버프 효과를 받을 시 10% 확률로 해당 효과에 면역한다 | 1 |
| 방패병이 받는 HP 회복 효과 +15% | 2 |
| 방패병이 받는 피해 -3 | 2 |

### 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |

| 방패병 주변에 아군이 없을 시 받는 피해 -20% | 1 |
