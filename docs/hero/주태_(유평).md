## 원조

5칸 내 아군이 받는 공격 피해의 [10-30]%만큼 대신 감당하며, 빈사 상태에 빠질 시, 100% 확률(발동될 때마다 -10%, 최소 50%까지)로 최대 HP의 20%에 해당하는 HP를 회복한다.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(무거운 방패)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(무거운 방패)의 공격력 +2 | 3 |
| 병사(무거운 방패)의 HP +20 | 3 |
| 병사(무거운 방패)의 공격력 +5% | 3 |
| 병사(무거운 방패)의 HP+5% | 3 |
| 병사(무거운 방패)이(가) 주는 피해 +5% | 3 |
| 병사(무거운 방패)이(가) 받는 피해 -5% | 3 |
| 병사(무거운 방패)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(무거운 방패)의 흡혈률 +8% | 2 |
| 병사(무거운 방패)의 회피률 +8% | 2 |
| 병사(무거운 방패)이(가) 회피률을 +8% 무시한다 | 2 |
| 방패병의 최대 분노치 -1 | 1 |
| 방패병이 디버프 효과를 받을 시 10% 확률로 해당 효과에 면역한다 | 1 |
| 방패병이 받는 HP 회복 효과 +15% | 2 |
| 방패병이 받는 피해 -3 | 2 |

### 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |
| 병사(무거운 방패)의 방어 자세 지속 시간 +1턴 | 1 |
| 병사(무거운 방패)의 HP가 처음 50% 미만으로 떨어질 경우, 최대 HP의 20%에 해당하는 HP를 회복한다 | 1 |
| 방패병이 공격 시 분노치가 1 추가 증가한다 | 1 |
| 방패병이 매 턴마다 [2%\*현재 HP]에 해당하는 HP를 회복한다 | 2 |
| 방패병은 턴당 30% 확률로 1칸 범위 내 최대 4명의 적에게 [자신 최대 HP\*2%]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 병사(무거운 방패)의 HP가 50% 미만인 상태에서 턴당 [최대 HP\*1%]에 해당하는 HP를 회복한다 | 1 |
