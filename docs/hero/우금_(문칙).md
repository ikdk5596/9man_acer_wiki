# 우금 (문칙)

## 굳셈

전투 시작 시, 자신의 군대 중 병기 이외의 병사들이 주는 피해와 받는 피해가 [50-100]%씩 증가하고, 동시에 디버프 효과를 면역한다. 해당 효과는 우금이 전사할 시 사라진다.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(맥도)의 공격력 +2 | 3 |
| 병사(맥도)의 HP +20 | 3 |
| 병사(맥도)의 공격력 +5% | 3 |
| 병사(맥도)의 HP+5% | 3 |
| 병사(맥도)이(가) 주는 피해 +5% | 3 |
| 병사(맥도)이(가) 받는 피해 -5% | 3 |
| 병사(맥도)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(맥도)의 흡혈률 +8% | 2 |
| 병사(맥도)의 회피률 +8% | 2 |
| 병사(맥도)이(가) 회피률을 +8% 무시한다 | 2 |
| 창병이 대상을 처치할 시 공격력 +1 | 1 |
| 창병이 공격을 시전할 시, 이미 잃은 HP 10%당 이번에 주는 피해 +10% | 2 |
| 창병 받는 HP 회복 효과 +15% | 2 |

### 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |
| 병사(맥도)이(가) 공격 시 30% 확률로 [30%\*공격력]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 창병이 피해를 받을 시, 공격자의 공격력이 자신보다 더 높을 경우, 해당 피해는 30%감소되어 적용된다 | 1 |
| 병사(맥도)가 피해 감면율을 30% 무시한다 | 1 |
| 창병의 공격 범위 +1 | 1 |
| 병사(맥도)의 HP가 최대치인 상태에서 주는 피해가 15% 증가한다 | 1 |
