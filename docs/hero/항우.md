## 패왕

스위프 피해가 ([5-10]x적중한 대상 수)% 증가하는 동시에, 공격 대상을 1칸 격퇴시키고, 1턴 동안 이동하지 못하도록 한다.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 기병(창)의 스킬 시전 후 분노치 1 보류 | 1 |
| 기병(창)의 공격력 +2 | 3 |
| 기병(창)의 HP +20 | 3 |
| 기병(창)의 공격력 +5% | 3 |
| 기병(창)의 HP+5% | 3 |
| 기병(창)이(가) 주는 피해 +5% | 3 |
| 기병(창)이(가) 받는 피해 -5% | 3 |
| 기병(창)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 기병(창)의 흡혈률 +8% | 2 |
| 기병(창)의 회피률 +8% | 2 |
| 기병(창)이(가) 회피율을 8% 무시한다 | 2 |
| 기병의 최대 분노치 -1 | 1 |
| 기병이 대상을 처치할 시 공격력 +1 | 1 |
| 기병의 HP가 처음 30% 미만으로 떨어질 경우, [최대 HP\*15%]에 해당하는 HP를 회복한다 | 2 |
| 기병이 받는 HP 회복 효과 +15% | 2 |

### 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |
| 기병(창)이(가) 공격 시 30% 확률로 [30%\*공격력]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 기병(창)이 피격당해 고정 피해를 받을 시, 그 피해의 30%에 해당하는 HP를 회복한다 | 1 |
| 기병(창)이 스킬 시전 후, 분노가 2 보류된다 | 1 |
| 기병이 공격 시 분노치가 1 추가 증가한다 | 1 |
| 기병이 공격할 시, 대상에게 현재 HP의 2%에 해당하는 추가 피해를 입힌다 | 2 |
| 기병이 준 피해의 20%가 고정 피해로 전환된다 | 1 |
| 적군 병사가 아군보다 많을 경우, 전체 아군 병사가 주는 피해 +20% | 1 |
