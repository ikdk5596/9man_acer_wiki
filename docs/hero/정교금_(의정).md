## 삼단 강타

공격 대상을 변경할 때마다 3회의 특수 공격을 추가 시전한다. 첫 공격은 단일 공격으로, 주는 피해가 50% 증가하고, 2번째 공격은 절단 공격으로, 적중한 대상 1명당 최대 HP의 5%에 해당하는 HP를 회복하며, 3번째 공격은 단일 공격으로, 공격 대상에게 [이미 손실한 HP\*[10-30]%]에 해당하는 추가 고정 피해를 입힌다.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 기병(도끼)의 공격력 +2 | 3 |
| 기병(도끼)의 HP +20 | 3 |
| 기병(도끼)의 공격력 +5% | 3 |
| 기병(도끼)의 HP+5% | 3 |
| 기병(도끼)이(가) 주는 피해 +5% | 3 |
| 기병(도끼)이(가) 받는 피해 -5% | 3 |
| 기병(도끼)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 기병(도끼)의 흡혈률 +8% | 2 |
| 기병(도끼)의 회피률 +8% | 2 |
| 기병(도끼)이(가) 회피율을 8% 무시한다 | 2 |
| 기병이 대상을 처치할 시 공격력 +1 | 1 |
| 기병의 HP가 처음 30% 미만으로 떨어질 경우, [최대 HP\*15%]에 해당하는 HP를 회복한다 | 2 |
| 기병이 받는 HP 회복 효과 +15% | 2 |

### 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |
| 기병(도끼)이(가) 공격 시 30% 확률로 [30%\*공격력]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 기병(도끼)이 대상의 보호막에 피해를 줄 시, 피해량에 해당하는 보호막을 획득한다 | 1 |
| 기병(도끼)이 보호막을 파괴할 시, 대상 주변 1칸 범위 내 최대 4명의 적에게 보호막의 100%에 해당하는 추가 고정 피해를 입힌다 | 1 |
| 기병이 공격할 시, 대상에게 현재 HP의 2%에 해당하는 추가 피해를 입힌다 | 1 |
| 기병이 준 피해의 20%가 고정 피해로 전환된다 | 2 |
| 기병(도끼)의 공격력 +10%, 주는 피해 +10% | 1 |
