## 회수창

긴 창을 목표 위치로 투사하고, 다음 턴에 공격을 하지 않고, 긴 창을 회수한다. 회수 시 목표 위치에 적이 없을 경우, 분노치가 75% 증가하고, 그렇지 않을 경우, [[100-150]%\*공격력]에 해당하는 피해를 입힌다.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(긴창)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(긴창)의 공격력 +2 | 3 |
| 병사(긴창)의 HP +20 | 3 |
| 병사(긴창)의 공격력 +5% | 3 |
| 병사(긴창)의 HP+5% | 3 |
| 병사(긴창)이(가) 주는 피해 +5% | 3 |
| 병사(긴창)이(가) 받는 피해 -5% | 3 |
| 병사(긴창)이(가) 턴당 HP를 2회복한다 | 3 |
