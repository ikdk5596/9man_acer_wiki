## 적장 참수

난무 시전 시 적군 영웅 또는 공격력이 가장 높은 대상을 향해 돌진하게 되고, [200%\*공격력]에 해당하는 피해를 1번 입히며, 받아넘기기 확률 +20%, 동시에 다음 2회의 일반 공격 시 [대상 최대 HP\*[15-30]%]에 해당하는 추가 피해를 입힌다.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(쌍창)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(쌍창)의 공격력 +2 | 3 |
| 병사(쌍창)의 HP +20 | 3 |
| 병사(쌍창)의 공격력 +5% | 3 |
| 병사(쌍창)의 HP+5% | 3 |
| 병사(쌍창)이(가) 주는 피해 +5% | 3 |
| 병사(쌍창)이(가) 받는 피해 -5% | 3 |
| 병사(쌍창)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(쌍창)의 흡혈률 +8% | 2 |
| 병사(쌍창)의 회피률 +8% | 2 |
| 병사(쌍창)이(가) 회피률을 +8% 무시한다 | 2 |
| 창병의 최대 분노치 -1 | 1 |
| 창병이 대상을 처치할 시 공격력 +1 | 1 |
| 창병이 공격을 시전할 시, 이미 잃은 HP 10%당 이번에 주는 피해 +10% | 2 |
| 창병 받는 HP 회복 효과 +15% | 2 |

### 고급재능

| 재능 | 중첩 가능 횟수 |

| 창병이(가) 영웅에게 주는 피해 +30% | 1 |
