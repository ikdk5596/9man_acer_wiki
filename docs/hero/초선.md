## 폐월

4턴마다 공격 범위 내의 영웅 또는 공격력이 가장 높은 적 1명을 2턴 동안 매혹 상태로 만들며, 매혹된 대상은 아군을 공격하고 공격 대상이 없을 경우 공격 대상은 자신의 공격력 [100-150]%의 추가 고정 피해를 입히며, 스킬이 최대 레벨에 달성하면 부여 대상이 1명 추가한다.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(쇠뇌)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(쇠뇌)의 공격력 +2 | 3 |
| 병사(쇠뇌)의 HP +20 | 3 |
| 병사(쇠뇌)의 공격력 +5% | 3 |
| 병사(쇠뇌)의 HP+5% | 3 |
| 병사(쇠뇌)이(가) 주는 피해 +5% | 3 |
| 병사(쇠뇌)이(가) 받는 피해 -5% | 3 |
| 병사(쇠뇌)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(쇠뇌)의 흡혈률 +8% | 2 |
| 병사(쇠뇌)의 회피률 +8% | 2 |

| 궁병의 공격력 +4 | 2 |
| 궁병의 최대 분노치 -1 | 1 |

| 궁병과 대상의 거리에 따라, 1칸당 궁병이 주는 피해가 2% 증가한다 | 2 |

| 재능 | 중첩 가능 횟수 |

| 병사(쇠뇌) 전속 장비의 기본 회피 확률 +10% | 1 |
