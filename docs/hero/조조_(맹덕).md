## 효웅

공격할 때마다 3칸 내 최대 20명의 아군에게 사기를 1스택씩 부여한다. 사기 1스택당 최대 HP +10, 공격력 +1(최대 [10-20]스택 중첩 가능), 조조가 전사하면 모든 사기는 제거된다.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(검&방패)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(검&방패)의 공격력 +2 | 3 |
| 병사(검&방패)의 HP +20 | 3 |
| 병사(검&방패)의 공격력 +5% | 3 |
| 병사(검&방패)의 HP+5% | 3 |
| 병사(검&방패)이(가) 주는 피해 +5% | 3 |
| 병사(검&방패)이(가) 받는 피해 -5% | 3 |
| 병사(검&방패)이(가) 턴당 HP를 2회복한다 | 3 |

| 재능 | 중첩 가능 횟수 |
|---|---:|

| 방패병이 받는 HP 회복 효과 +15% | 2 |
| 방패병이 받는 피해 -3 | 2 |

| 재능 | 중첩 가능 횟수 |
