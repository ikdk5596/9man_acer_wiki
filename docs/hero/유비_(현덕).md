## 인덕

연사 시 적에게 피해를 주지 않고, 대신 HP(%)가 가장 낮은 아군에게 최대 HP의 [10-20]%에 해당하는 HP를 회복시킨다. 자신이 최대 레벨을 달성한 경우, 회복 효과가 30% 증가한다. (전용 장비 효과: 연사 횟수 +1)

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(쇠뇌)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(쇠뇌)의 공격력 +2 | 3 |
| 병사(쇠뇌)의 HP +20 | 3 |
| 병사(쇠뇌)의 공격력 +5% | 3 |
| 병사(쇠뇌)의 HP+5% | 3 |
| 병사(쇠뇌)이(가) 주는 피해 +5% | 3 |
| 병사(쇠뇌)이(가) 받는 피해 -5% | 3 |
| 병사(쇠뇌)이(가) 턴당 HP를 2회복한다 | 3 |

| 재능 | 중첩 가능 횟수 |
|---|---:|

| 병사(쇠뇌)의 회피률 +8% | 2 |
| 병사(쇠뇌)이(가) 회피률을 +8% 무시한다 | 2 |

| 궁병의 최대 분노치 -1 | 1 |

| 재능 | 중첩 가능 횟수 |
