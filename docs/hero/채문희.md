# 채문희

<img src="/images/hero/채문희.png" alt="채문희" style="width: 280px; max-width: 100%; height: 340px; object-fit: contain; object-position: left center; image-rendering: pixelated;">

| 항목 | 내용 |
| --- | --- |
| 빙의 병종 | [사냥꾼](/soldiers/사냥꾼) |
| HP | [50-100] |
| 공격력 | [4-10] |

## 비가

격려 시 HP가 가장 낮은 아군 3명에게 최대 HP 5%의 HP를 회복시키고, [50-100]% 확률로 공격 시 공격력 30%의 고정 피해를 추가한다. 3턴간 지속되며 자신이 최고 레벨일 때 시전 대상+3.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(사냥꾼)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(사냥꾼)의 공격력 +2 | 3 |
| 병사(사냥꾼)의 HP +20 | 3 |
| 병사(사냥꾼)의 공격력 +5% | 3 |
| 병사(사냥꾼)의 HP+5% | 3 |
| 병사(사냥꾼)이(가) 주는 피해 +5% | 3 |
| 병사(사냥꾼)이(가) 받는 피해 -5% | 3 |
| 병사(사냥꾼)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(사냥꾼)의 흡혈률 +8% | 2 |
| 병사(사냥꾼)의 회피률 +8% | 2 |
| 병사(사냥꾼)이(가) 회피률을 +8% 무시한다 | 2 |
| 궁병의 공격력 +4 | 2 |
| 궁병의 최대 분노치 -1 | 1 |
| 궁병이 대상을 처치할 시 공격력 +1 | 1 |
| 궁병과 대상의 거리에 따라, 1칸당 궁병이 주는 피해가 3% 증가한다 | 2 |

### 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|

| 사냥꾼이 야외 몬스터를 공격할 시, 공격력 +20% | 1 |

| 궁병이 공격 시 분노치가 1 추가 증가한다 | 1 |
| 사냥꾼이 격려를 시전 시 20% 확률로 아군의 디버프 효과를 1개 제거한다 | 1 |
