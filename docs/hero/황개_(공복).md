## 고육책

첫 턴이 시작될 시, 자신 최대 HP의 20%에 해당하는 HP가 감소되고, 가장 가까운 30명의 아군과 자신에게 [20-50]%에 해당하는 보호막을 부여하는 동시, 공격력을 10% 증가시킨다. (전투가 종료될 때까지 지속)

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(망치&방패)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(망치&방패)의 공격력 +2 | 3 |
| 병사(망치&방패)의 HP +20 | 3 |
| 병사(망치&방패)의 공격력 +5% | 3 |
| 병사(망치&방패)의 HP+5% | 3 |
| 병사(망치&방패)이(가) 주는 피해 +5% | 3 |
| 병사(망치&방패)이(가) 받는 피해 -5% | 3 |
| 병사(망치&방패)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(망치&방패)의 흡혈률 +8% | 2 |
| 병사(망치&방패)의 회피률 +8% | 2 |
| 병사(망치&방패)이(가) 회피률을 +8% 무시한다 | 2 |
| 방패병의 최대 분노치 -1 | 1 |
| 방패병이 디버프 효과를 받을 시 10% 확률로 해당 효과에 면역한다 | 1 |
| 방패병이 받는 HP 회복 효과 +15% | 2 |
| 방패병이 받는 피해 -3 | 2 |

### 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
