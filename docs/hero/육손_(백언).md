## 연영

불화살을 발사한 후, 아군 땅에 있는 불이 [20-50]% 확률로 적군 방향으로 1칸 확산된다.

## 재능

### 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(화궁)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(화궁)의 공격력 +2 | 3 |
| 병사(화궁)의 HP +20 | 3 |
| 병사(화궁)의 공격력 +5% | 3 |
| 병사(화궁)의 HP+5% | 3 |
| 병사(화궁)이(가) 주는 피해 +5% | 3 |
| 병사(화궁)이(가) 받는 피해 -5% | 3 |
| 병사(화궁)이(가) 턴당 HP를 2회복한다 | 3 |

### 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(화궁)의 흡혈률 +8% | 2 |
| 병사(화궁)의 회피률 +8% | 2 |
| 병사(화궁)이(가) 회피률을 +8% 무시한다 | 2 |
| 궁병의 공격력 +4 | 2 |
| 궁병의 최대 분노치 -1 | 1 |
| 궁병이 대상을 처치할 시 공격력 +1 | 1 |
| 궁병과 대상의 거리에 따라, 1칸당 궁병이 주는 피해가 3% 증가한다 | 2 |

| 재능 | 중첩 가능 횟수 |

| 병사(화궁)가 불화살 발사 시 50% 확률로 공격이 적군 방향으로 1칸 확산된다 | 1 |
