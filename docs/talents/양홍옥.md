# 양홍옥

## 도감 분류

- 유형: 궁병
- 병종: 사냥꾼

## 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(사냥꾼)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(사냥꾼)의 공격력 +2 | 3 |
| 병사(사냥꾼)의 HP +20 | 3 |
| 병사(사냥꾼)의 공격력 +5% | 3 |
| 병사(사냥꾼)의 HP+5% | 3 |
| 병사(사냥꾼)이(가) 주는 피해 +5% | 3 |
| 병사(사냥꾼)이(가) 받는 피해 -5% | 3 |
| 병사(사냥꾼)이(가) 턴당 HP를 2회복한다 | 3 |

## 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(사냥꾼)의 흡혈률 +8% | 2 |
| 병사(사냥꾼)의 회피률 +8% | 2 |
| 병사(사냥꾼)이(가) 회피률을 +8% 무시한다 | 2 |
| 궁병의 공격력 +4 | 2 |
| 궁병의 최대 분노치 -1 | 1 |
| 궁병이 대상을 처치할 시 공격력 +1 | 1 |
| 궁병과 대상의 거리에 따라, 1칸당 궁병이 주는 피해가 3% 증가한다 | 2 |

## 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |
| 병사(사냥꾼)이(가) 공격 시 30% 확률로 [30%*공격력]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 사냥꾼이 야외 몬스터를 공격할 시, 공격력 +20% | 1 |
| 사냥꾼 전용 장비 효과로 회복하는 아군 HP +5 | 1 |
| 궁병의 공격 범위 +1 | 1 |
| 궁병이 공격 시 분노치가 1 추가 증가한다 | 1 |
| 사냥꾼이 시전한 격려의 지속 시간 +1턴 | 1 |
