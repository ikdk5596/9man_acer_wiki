# 하후연

## 도감 분류

- 유형: 기병
- 병종: 활

## 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 기병(활)의 스킬 시전 후 분노치 1 보류 | 1 |
| 기병(활)의 공격력 +2 | 3 |
| 기병(활)의 HP +20 | 3 |
| 기병(활)의 공격력 +5% | 3 |
| 기병(활)의 HP+5% | 3 |
| 기병(활)이(가) 주는 피해 +5% | 3 |
| 기병(활)이(가) 받는 피해 -5% | 3 |
| 기병(활)이(가) 턴당 HP를 2회복한다 | 3 |

## 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 기병(활)의 흡혈률 +8% | 2 |
| 기병(활)의 회피률 +8% | 2 |
| 기병(활)이(가) 회피율을 8% 무시한다 | 2 |
| 기병의 최대 분노치 -1 | 1 |
| 기병이 대상을 처치할 시 공격력 +1 | 1 |
| 기병의 HP가 처음 30% 미만으로 떨어질 경우, [최대 HP*15%]에 해당하는 HP를 회복한다 | 2 |
| 기병이 받는 HP 회복 효과 +15% | 2 |

## 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |
| 기병의 이동 범위 +1 | 1 |
| 기병(활)이(가) 공격 시 30% 확률로 [30%*공격력]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 기병(활)의 공격력 +20% | 1 |
| 기병이 공격 시 분노치가 1 추가 증가한다 | 1 |
| 기병이 공격할 시, 대상에게 현재 HP의 2%에 해당하는 추가 피해를 입힌다 | 2 |
| 기병이 준 피해의 20%가 고정 피해로 전환된다 | 1 |
| 기병(활)이 1칸 이동할 때마다 공격력 +1% (최대 50회 중첩 가능) | 1 |
