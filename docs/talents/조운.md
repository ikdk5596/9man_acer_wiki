# 조운

## 도감 분류

- 유형: 창병
- 병종: 장창

## 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(장창)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(장창)의 공격력 +2 | 3 |
| 병사(장창)의 HP +20 | 3 |
| 병사(장창)의 공격력 +5% | 3 |
| 병사(장창)의 HP+5% | 3 |
| 병사(장창)이(가) 주는 피해 +5% | 3 |
| 병사(장창)이(가) 받는 피해 -5% | 3 |
| 병사(장창)이(가) 턴당 HP를 2회복한다 | 3 |

## 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(장창)의 흡혈률 +8% | 2 |
| 병사(장창)의 회피률 +8% | 2 |
| 병사(장창)이(가) 회피률을 +8% 무시한다 | 2 |
| 창병의 최대 분노치 -1 | 1 |
| 창병이 대상을 처치할 시 공격력 +1 | 1 |
| 창병이 공격을 시전할 시, 이미 잃은 HP 10%당 이번에 주는 피해 +10% | 2 |
| 창병 받는 HP 회복 효과 +15% | 2 |

## 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |
| 병사(장창)이(가) 공격 시 30% 확률로 [30%*공격력]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 병사(장창)가 찌르기 공격 시전 시, HP 회복 효과는 [50%*이미 손실한 HP]에 해당하는 값으로 변경된다 | 1 |
| 창병이 공격 시 (5*자신의 레벨)에 해당하는 HP를 회복한다 | 1 |
| 창병의 공격 범위 +1 | 1 |
| 창병이 공격 시 분노치가 1 추가 증가한다 | 1 |
| 병사(장창) 회피 성공 시 최대 HP의 2%에 해당하는 HP를 회복한다 | 1 |
| 창병 임의 회피 +5%, 회피 후 분노치 +1 | 1 |
