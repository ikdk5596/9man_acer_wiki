# 손상향

## 도감 분류

- 유형: 궁병
- 병종: 강화 쇠뇌

## 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(강화 쇠뇌)의 공격력 +2 | 3 |
| 병사(강화 쇠뇌)의 HP +20 | 3 |
| 병사(강화 쇠뇌)의 공격력 +5% | 3 |
| 병사(강화 쇠뇌)의 HP+5% | 3 |
| 병사(강화 쇠뇌)이(가) 주는 피해 +5% | 3 |
| 병사(강화 쇠뇌)이(가) 받는 피해 -5% | 3 |
| 병사(강화 쇠뇌)이(가) 턴당 HP를 2회복한다 | 3 |

## 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(강화 쇠뇌)의 흡혈률 +8% | 2 |
| 병사(강화 쇠뇌)의 회피률 +8% | 2 |
| 병사(강화 쇠뇌)이(가) 회피률을 +8% 무시한다 | 2 |
| 궁병의 공격력 +4 | 2 |
| 궁병이 대상을 처치할 시 공격력 +1 | 1 |
| 궁병과 대상의 거리에 따라, 1칸당 궁병이 주는 피해가 3% 증가한다 | 2 |

## 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 2 |
| 병사(강화 쇠뇌)이(가) 공격 시 30% 확률로 [30%*공격력]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 병사(강화 쇠뇌)가 대상을 격퇴할 시, 해당 대상은 1턴간 이동하지 못한다 | 1 |
| 병사(강화 쇠뇌)가 활시위를 당긴 후, 2턴간 사격한다 | 1 |
| 궁병의 공격 범위 +1 | 1 |
| 병사(강화 쇠뇌)가 처음으로 빈사 상태에 빠질 시, [최대 HP*50%]에 해당하는 HP를 회복한다 | 1 |
