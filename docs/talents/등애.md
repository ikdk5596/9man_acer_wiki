# 등애

## 도감 분류

- 유형: 방패병
- 병종: 검&방패

## 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(검&방패)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(검&방패)의 공격력 +2 | 3 |
| 병사(검&방패)의 HP +20 | 3 |
| 병사(검&방패)의 공격력 +5% | 3 |
| 병사(검&방패)의 HP+5% | 3 |
| 병사(검&방패)이(가) 주는 피해 +5% | 3 |
| 병사(검&방패)이(가) 받는 피해 -5% | 3 |
| 병사(검&방패)이(가) 턴당 HP를 2회복한다 | 3 |

## 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(검&방패)의 흡혈률 +8% | 2 |
| 병사(검&방패)의 회피률 +8% | 2 |
| 병사(검&방패)이(가) 회피률을 +8% 무시한다 | 2 |
| 방패병의 최대 분노치 -1 | 1 |
| 방패병이 디버프 효과를 받을 시 10% 확률로 해당 효과에 면역한다 | 1 |
| 방패병이 받는 HP 회복 효과 +15% | 2 |
| 방패병이 받는 피해 -3 | 2 |

## 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |
| 병사(검&방패)이(가) 공격 시 30% 확률로 [30%*공격력]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 병사(검&방패)에게 돌파가 최대 스택까지 중첩된 후 HP +15%, 공격력 +15% | 1 |
| 병사(검&방패)의 전용 장비 효과 중 피해 증가량이 5%(으)로 변경된다 | 1 |
| 방패병이 공격 시 분노치가 1 추가 증가한다 | 1 |
| 방패병이 매 턴마다 [2%*현재 HP]에 해당하는 HP를 회복한다 | 2 |
| 방패병은 턴당 30% 확률로 1칸 범위 내 최대 4명의 적에게 [자신 최대 HP*2%]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 턴 시작 시마다 아군 전체는 HP를 10 회복한다 | 1 |
