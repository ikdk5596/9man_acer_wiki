# 초선

## 도감 분류

- 유형: 궁병
- 병종: 쇠뇌

## 초급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(쇠뇌)의 스킬 시전 후 분노치 1 보류 | 1 |
| 병사(쇠뇌)의 공격력 +2 | 3 |
| 병사(쇠뇌)의 HP +20 | 3 |
| 병사(쇠뇌)의 공격력 +5% | 3 |
| 병사(쇠뇌)의 HP+5% | 3 |
| 병사(쇠뇌)이(가) 주는 피해 +5% | 3 |
| 병사(쇠뇌)이(가) 받는 피해 -5% | 3 |
| 병사(쇠뇌)이(가) 턴당 HP를 2회복한다 | 3 |

## 중급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 병사(쇠뇌)의 흡혈률 +8% | 2 |
| 병사(쇠뇌)의 회피률 +8% | 2 |
| 병사(쇠뇌)이(가) 회피률을 +8% 무시한다 | 2 |
| 궁병의 공격력 +4 | 2 |
| 궁병의 최대 분노치 -1 | 1 |
| 궁병이 대상을 처치할 시 공격력 +1 | 1 |
| 궁병과 대상의 거리에 따라, 1칸당 궁병이 주는 피해가 2% 증가한다 | 2 |

## 고급재능

| 재능 | 중첩 가능 횟수 |
|---|---:|
| 영웅이 주는 피해 +30%, 받는 피해 -30% | 1 |
| 병사(쇠뇌)이(가) 공격 시 30% 확률로 [30%*공격력]에 해당하는 고정 피해를 추가 부여한다 | 1 |
| 병사(쇠뇌)가 연사 시 50% 확률로 1회 추가 사격한다 | 2 |
| 병사(쇠뇌)가 사격을 5회 진행할 때마다 [3%대상의 최대 HP]에 해당하는 추가 피해를 입힌다 | 1 |
| 궁병의 공격 범위 +1 | 1 |
| 궁병이 공격 시 분노치가 1 추가 증가한다 | 1 |
| 병사(쇠뇌) 전속 장비의 기본 회피 확률 +10% | 1 |
